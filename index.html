Everything here is fiction

Kestrel Freight Ltd, its people, systems and logs are invented for training. Every address is reserved for documentation or private, and every domain ends in .example, .test or .invalid. Nothing in the packs is malware or attack tooling. Because the data is synthetic, it's safe to use with an AI assistant.

How to start

  1. Unzip the download. It holds one folder, hands-on-labs, with a folder per chapter.
  2. Read README-FIRST.md, then the README.md in the chapter you're working on.
  3. Check your copy by running python -I verify.py in a chapter's folder. It recomputes the numbers the chapter quotes and prints whether they pass.

To check the whole download, compare its SHA-256 with the value above:

Windows PowerShell:  Get-FileHash hands-on-labs-v1.0.zip
Linux or macOS:      sha256sum hands-on-labs-v1.0.zip

Inside the zip, SHA256SUMS.txt lists the hash of every file.

Rules that come with every pack

  • Don't query the real internet for any value in a pack. The lookups you need are simulated in the pack.
  • Decode with deterministic tools, and never run decoded content.
  • The data is dated in 2026. Replace ago() or relative time ranges with the fixed dates in the pack's README.
  • Read an answer key only after you've committed to your own answers.
